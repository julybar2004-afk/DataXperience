# 📊 Dataset: Alojamientos Turísticos en Bogotá (`Data.csv`)

Este archivo contiene el conjunto de datos utilizado para el análisis exploratorio, limpieza estadística y modelado predictivo de precios de alojamientos temporales en Bogotá, Colombia.

---

## 📋 Descripción General

* **Archivo:** `Data.csv`
* **Fuente:** https://insideairbnb.com/es/get-the-data/
* **Dimensiones originales:** `19.505` registros (filas) y `19` variables (columnas)
* **Cobertura geográfica:** Localidades y barrios de Bogotá D.C., Colombia
